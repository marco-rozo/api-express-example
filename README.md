# API Express Example

API criada para criação e testes de uma rota de login em um App

## Getting started
Install 

```
$ yarn install
```
run 

```
$ yarn dev
```

### Obs

Para simplificar a execução do projeto e evitar a necessidade de configurar uma conexão com banco de dados, o processo de autenticação foi simulado no `AuthController`.  

Os usuários utilizados para o login são definidos em uma lista estática no projeto, que pode ser consultada [neste arquivo](https://github.com/marco-rozo/api-express-example/blob/master/src/data/users.ts).
